# Databand (DBND)

> DBND (Databand) is an open-source Python framework — a library, a set of APIs, and a CLI — for building, tracking, and observing data pipelines across ingestion, preparation, ETL/ELT, and machine-learning workflows. It collects pipeline metadata (runs, metrics, dataframes, schemas) to give data-engineering teams a system of record for detecting pipeline failures and data-quality issues. Databand was acquired by IBM in 2022 and is now IBM Databand, part of IBM's data-observability offering; the open-source DBND SDK remains published on PyPI and GitHub.
